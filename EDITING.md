# Как менять профиль

Открой [profile.json](profile.json), нажми карандаш и измени значения внутри кавычек:

- `project_name` — название проекта, до 60 символов.
- `description` — описание, до 360 символов; переносы оформляются автоматически.
- `project_url` — HTTPS-ссылка, открываемая при нажатии на карточку.
- `releases_url` — HTTPS-ссылка для кнопки «Релизы».

Нажми **Commit changes**. GitHub Actions → **Render profile** пересоберёт картинки и ссылки. Не редактируй SVG вручную. Если появилась красная ошибка, открой запуск: он покажет неверное поле; предыдущее оформление останется на месте.

Кавычки внутри текста записывай как `\"`. Не удаляй запятые между полями. Логотипы хранятся отдельно в `assets/icons/`; общий фон и подписи создаёт генератор. Файлы вне отмеченной области README он не меняет.

Локальная проверка без дополнительных библиотек:

```sh
python -m unittest discover -s scripts -p 'test_*.py'
python scripts/render_profile.py
```
